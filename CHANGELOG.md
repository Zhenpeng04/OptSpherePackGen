# Changelog

## [1.0.0] - 2026-10-03

### Features

- Local GUI, command-line interface and Python API for microsphere geometry.
- SC, BCC, FCC, diamond cubic and HCP crystal structures.
- Poisson-disk, RSA, force-biased, Lubachevsky–Stillinger and Metropolis
  generation of non-overlapping random packings.
- Marked Poisson Boolean media with configurable expected coverage.
- Monodisperse, quasi-monodisperse, continuous and discrete size distributions,
  including custom particle-size files.
- Periodic boxes with independent lateral length and depth, automatic particle
  counts and compatible crystal-cell dimensions.
- Geometry validation, generator diagnostics, nearest-neighbor statistics,
  pair correlation and structure factor.
- Real-unit and dimensionless CSV, JSON metadata, optional HDF5, exact geometry
  snapshots and PNG plots.
- Recorded seeds, archived inputs, checksums and portable result bundles
  with replay configurations.
- Persistent GUI history, separate run directories, progress, cancellation
  and configurable run time limits.
- English and Simplified Chinese README and user guide.

### Installation

- Python 3.10 or newer on Windows, macOS and Linux.
- Source and wheel installation with packaged example configurations.
